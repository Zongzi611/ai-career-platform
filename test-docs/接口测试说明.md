## 测试方法说明

### Token 传递机制

1. 登录请求的 Tests 脚本将返回的 token 写入集合变量：

```javascript
const json = pm.response.json();
if (json.data && json.data.token) {
    pm.collectionVariables.set("token", json.data.token);
}
```

2. 受保护接口通过 Header 携带 Token：

```
Authorization: Bearer {{token}}
```

### 权限验证

| 验证点 | 方法 | 结果 |
|--------|------|------|
| 白名单接口可匿名访问 | 不带 Token 访问 /api/health、/api/auth/login、/api/career/** | ✅ 正常返回 |
| 受保护接口拒绝匿名访问 | 不带 Token 访问 /api/assessment/** | ✅ 返回 401 "未登录或 Token 已过期" |
| 有效 Token 正常访问 | 带 Token 访问受保护接口 | ✅ 正常返回数据 |

## 使用方式

1. Postman 中 Import 本 Collection 文件
2. 配置 Collection Variables：`baseUrl` = `http://localhost:8080`、`token`（由登录请求自动写入）
3. 确保后端服务已启动，依次执行各请求
4. 查看 Test Results 验证断言结果
